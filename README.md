# Sommerløpet 2027

Kampanjelandingsside for **Sparebanken Norge Sommerløpet 2027**, som arrangeres 5. juni 2027 i Kristiansand. Siden er utviklet for en Snapchat-kampanje og leder brukeren fra annonse til landingsside og videre til påmelding.

**Live nettside:** [sommerlopet-landing.vercel.app](https://sommerlopet-landing.vercel.app/)

## Teknologi

- React
- Vite
- JavaScript
- CSS
- Playwright
- Vercel

## Funksjoner

- Responsivt design for mobil, nettbrett og desktop
- Automatisk roterende Sommerløpet-bilder
- Støtte for redusert bevegelse (reduced motion)
- Klikkbare distansekort med informasjon om hvert løp
- Direkte lenker til påmelding for Sommerløpet 2027
- Tester for tilgjengelighet og responsivitet

## Kjør lokalt

Krever Node.js 22.12 eller nyere og npm.

```bash
npm install
npm run dev
```

Åpne adressen Vite viser i terminalen, normalt [127.0.0.1:5173](http://127.0.0.1:5173/).
